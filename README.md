# PROJETO STELVE FRAMEWORK - JOAO E BRENO

## O que é o framework escolhido?
* O Svelte é um framework JavaScript moderno para construção de interfaces web que atua como um compilador, e não como uma biblioteca de tempo de execução, Diferente de React ou Vue, o Svelte transforma o código em JavaScript puro e ultra-otimizado durante o build. No navegador, não sobra nada do framework, apenas o seu código pronto para rodar, Ele utiliza HTML, CSS e JavaScript quase puros. Você escreve menos linhas para criar componentes reativos, o que facilita a manutenção e o aprendizado.

## Por que utilizá-lo?
* Como ele é um compilador, o navegador recebe apenas JavaScript puro. Isso elimina o "atraso" que outros frameworks causam ao carregar, Ele não perde tempo comparando versões do site (Virtual DOM); ele altera o HTML instantaneamente quando o dado muda, Você escreve cerca de 30% a 40% menos código do que no React para fazer a mesma tarefa, Ideal para iniciantes ou equipes que precisam de agilidade, pois utiliza o padrão clássico da web (HTML, CSS e JS) sem inventar regras complexas.


## Em quais cenários ele não é indicado?
* Quando NÃO é indicado?

Mercado de Trabalho: Se o objetivo for apenas encontrar o maior volume de vagas (React ainda domina).

Ecossistema: Se você precisa de muitas bibliotecas prontas e complexas que só existem para frameworks mais antigos.

Mobile Nativo: Se o foco for criar apps de celular (iOS/Android) com alta maturidade, onde o React Native ainda é o padrão.
