# PROJETO STELVE FRAMEWORK - JOAO E BRENO

## O que é o framework escolhido?
* O Svelte é um framework JavaScript moderno para construção de interfaces web que atua como um compilador, e não como uma biblioteca de tempo de execução, Diferente de React ou Vue, o Svelte transforma o código em JavaScript puro e ultra-otimizado durante o build. No navegador, não sobra nada do framework, apenas o seu código pronto para rodar, Ele utiliza HTML, CSS e JavaScript quase puros. Você escreve menos linhas para criar componentes reativos, o que facilita a manutenção e o aprendizado.
